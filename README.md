# Boxy Bunch Playtest

Boxy Bunch gri kutu deneme oyununun playtest derlemesi. Bu depo yalnız derlenmiş dosyaları taşır ve GitHub Pages ile yayınlanır; kaynak kod gizli `iamhtt/BoxyBunch` deposundadır. Yayınlanan sürüm `gh-pages` dalındadır ve her sürümde oyun deposunun playtest derlemesinden (`npm run build:playtest`) yeniden üretilir; bu dalda elle değişiklik yapılmaz.
